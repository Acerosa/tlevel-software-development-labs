# tlevel-software-development-labs

Teaching materials for T Level Software Development. The repository holds project briefs, starter applications, exercises, and shared resources.

## Projects

Each project has its own folder under `projects/`, with a README, a `brief/`, and a `starter/` when an application is provided.

## Starter applications

When a starter is available, it is in that project's `starter/` folder. Copy it into your own working area before you change it. The library project does not include a starter yet.

## Your own copy

Clone or fork the repository and work in your own copy. Keep your work on your own branch so the shared materials stay intact for the rest of the group.

## Teamwork, testing and integration

Projects may be split across teams. Teams build and test their own part, then integrate the parts into one system.
